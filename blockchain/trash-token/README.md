# trash-token

Trash Coin (`TRASH`): a NEP-141 / NEP-145 fungible token for NEAR Testnet, built on
the official `near-contract-standards` reference implementation. It has 24 decimals,
and the smallest unit is yoctoTRASH. The full supply is minted once to the owner.
`ft_burn` lets any holder burn their own tokens.

**TRASH has no real-world value.** It is not deployed to testnet yet.

Build, tests, and deployment are described in [../README.md](../README.md).
