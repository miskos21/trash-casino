# trash-casino

Escrow for match buy-ins, single settlement from the authorized settler, cancel and
deadline refunds, paid NPC deals, and NPC spending limits (`agent_pay`) enforced by
the contract. Spending limits are not enforced only in Java.

NEAR Testnet only. TRASH has no real-world value. Not deployed yet.

Design, API, trust assumptions, and commands are in [../README.md](../README.md).
